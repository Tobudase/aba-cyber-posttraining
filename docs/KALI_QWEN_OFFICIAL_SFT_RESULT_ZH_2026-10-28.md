# KaliBench 官方 TRAIN 内部开发试点：Qwen3-8B SFT 结果（2026-10-28）

## 做了什么

以固定版本 [Qwen/Qwen3-8B](https://huggingface.co/Qwen/Qwen3-8B) 为底座，从 [KaliBench-Verified](https://huggingface.co/datasets/RISys-Lab/KaliBench) 的**官方 TRAIN** 中筛选发布方标记 `ACCURATE`、终端 `PASS_EXECUTED` 且通过本地评分一致性检查的记录。先按工具和空白标准化后的标准命令分组，再锁定 512 条训练、128 条内部开发题；两边没有精确问题或标准命令交叉。发布方核验属于**银标**，并非逐条独立专家金标。官方 TEST 从未读取。

2026-10-28 在 Nautilus 上用**单张 RTX 3090** 运行了完整的训练前基线 → 固定 SFT → 同题复测。模型权重 11 个文件（含 5 个 BF16 分片）先在 CPU Job 中下载并按固定 revision 校验；GPU 作业也重新核验文件。运行配置是 NF4 量化底座、BF16 计算、全层 `q_proj/v_proj` LoRA rank 16 / alpha 32、batch 1、学习率 `2e-5`、1 epoch 共 **512 个优化步**、seed 3407、贪心生成、最多 512 个新 token。基线和复测使用同一模型量化配置、提示词与生成参数。该配置是**固定 SFT**，没有运行 ABA 自动搜索。

最初的 BF16 A6000、A100 与 L40 单卡任务均未获得调度，且在任何模型调用或 GPU 分配前清理；3090 的 12 GiB 主机内存请求也未排上。随后将主机请求降至 8 GiB，以单张 3090 完成 NF4 QLoRA。这个精度变更发生在首次模型输出前，因此本表只做**3090/NF4 协议内部的训练前后配对比较**，不与早期 RedSage-K/BF16 数值直接比较。

## 128 条内部开发题的成对结果

| 指标 | 训练前 | 训练后 | 变化 |
|---|---:|---:|---:|
| 严格工具／选项值正确率 | 29/128（22.66%） | 43/128（33.59%） | +14 题，+10.94 个百分点 |
| 精确命令字符串匹配 | 25/128（19.53%） | 36/128（28.13%） | +11 题，+8.59 个百分点 |
| KaliBench 原生 `total_score` | 56.06 | 69.10 | +13.04 |
| KaliBench 原生 `exact_match` | 23.44% | 34.38% | +10.94 个百分点 |
| 完整 `<output>` 块 | 125/128 | 128/128 | +3 题 |
| 达到生成上限而截断 | 3/128 | 0/128 | −3 题 |

严格指标成对转移：**17 题从错变对、3 题从对变错、26 题保持正确、82 题保持错误**；增益分布于 16 种工具，退步分布于 3 种工具。精确命令指标对应 12 题转对、1 题转错。原生 `total_score` 可能忽略错误的选项值，因此额外报告严格指标；精确字符串匹配又可能把语义等价命令判错，因此不能单独代表真实安全操作能力。

事后检查发现训练集有 4 条、开发集有 **1 条**题面直接包含标准命令。该开发题训练前后均正确，因此不能提供训练收益证据；只排除这 1 条后的敏感性结果仍是严格正确 **28/127 → 42/127**、精确命令 **24/127 → 35/127**。保留原先冻结的 128 题主结果，不在看到输出后悄悄改写开发集。其余题是否存在语义近似提示，还需要进一步人工审查。

## 回执、资源与边界

GPU 作业回执记录 512 次优化、总运行约 2,123 秒（其中初始化约 295 秒）、峰值 CUDA 已分配约 10.28 GB。保存的 LoRA 适配器约 30.69 MB；独立的 CPU Job 在自有 PVC 上重算 SHA-256，和 GPU 回执一致。训练前／后预测、协议和评分回执的哈希在本机复核通过。自有 GPU Job、Pod、ConfigMap 与适配器核验 CPU Job 均已清理。

**这是一次有积极信号的内部开发试验，不是官方 KaliBench 分数，也不足以直接替换正式底座。** 开发题从官方 TRAIN 内部划出，虽然命令分组隔离，但尚未做外部盲测；只有一个随机种子，语义近似题与预训练污染风险仍需进一步排查。正式下一步应先审查收益／退步案例，再用另一个冻结的独立来源保持集复核，并与 RedSage-K 做匹配协议比较。官方 TEST 留给最终定稿后的单次评测；ABA 自动数据生成仍是后续独立实验。
