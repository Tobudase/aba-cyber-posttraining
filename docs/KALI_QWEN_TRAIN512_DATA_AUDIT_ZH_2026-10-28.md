# KaliBench Qwen3-8B：512 条 SFT 训练数据静态审计（2026-10-28）

## 审计对象与边界

对前次固定 512 步 SFT 使用的 **512 条 KaliBench 官方 TRAIN** 样本做只读结构、来源和重复性检查。输入文件与原有冻结清单的 SHA-256 一致；每条都能对应发布方的 `ACCURATE` 和终端 `PASS_EXECUTED` 记录，且训练目标遵循固定的 `<output>…</output>` 格式。这些是**发布方银标**，不能称为独立专家审核通过。

本次没有运行任何样本命令，没有模型推理、GPU 作业、优化步骤或官方 TEST 访问。逐题问题、命令、ID 与待复核清单仅保存在私有工作区；[公开汇总](../results/kali-qwen-train512-audit-2026-10-28/summary.json)只有计数和文件哈希。

## 结果

| 检查 | 发现 | 含义 |
| --- | ---: | --- |
| 训练样本 / 工具 | 512 / 275 | 工具覆盖广，但每种工具的样本较少。 |
| 只有 1 条训练样本的工具 | 165 | 很难单靠一条例子学到稳定的工具用法。 |
| 唯一标准化问题 | 512 | 未发现训练集内部的精确问题重复。 |
| 唯一“工具＋标准命令”组 | 503 | 14 条样本落在 5 个重复命令组，可检查是否过度重复。 |
| 题面直接包含完整参考命令 | 5 | 多为题目明确要求该命令，不等于数据泄漏；这些题较容易。 |
| 参考命令至少 120 字符 | 2 | 只是人工复核提示，不代表错误。 |
| 目标格式不匹配 | 0 | 所有目标字符串与冻结编码约定一致。 |
| 已独立人工审核的训练样本 | 0 | 尚不能给出专家确认的标签正确率。 |

按大小写和空白标准化后，训练 512 条与先前内部 DEV128、后续主结果 DEV87 都没有**精确问题**或**“工具＋命令”组**重叠。DEV87 里有 22 条工具完全未见于 TRAIN512，前次严格诊断在这 22 条上是 5/22→5/22。这些集合仍来自同一发布方 TRAIN 来源，精确去重不能排除语义近似，也不能构成独立来源验证。

审计器先前的粗略字符检查曾把两条命令中的引号内 `|` 当成 shell 管道提示；改成引号感知扫描后，该提示为 **0 条**。这说明自动审计的提示需要人工解释，不能直接删除样本。

对**已有、已经查询过**的 DEV87 输出作事后分层，按某工具在 TRAIN512 中出现的次数统计：

| 工具训练样本数 | DEV87 题数 | 训练前→训练后严格正确 | 转对／转错 |
| --- | ---: | ---: | ---: |
| 0 | 22 | 5→5 | 1／1 |
| 1 | 37 | 9→12 | 3／0 |
| 至少 2 | 28 | 4→9 | 5／0 |

这与“增益集中在训练见过的工具上”一致，但分组是**事后描述**，每组题量小、标签仍是银标，也可能受工具难度影响；不能据此证明多给某工具样本就一定改善。没有为这个分析再次查询模型。[无逐题内容的分层汇总](../results/kali-qwen-train512-audit-2026-10-28/coverage-posthoc.json)及[复算脚本](../scripts/analyze-kali-qwen-coverage-posthoc.py)另存。

## 复核与下一轮实验

私有审计包已按固定规则列出全部 512 条复核队列，并标出优先复核 64 条及确定性抽样 32 条。优先队列含命令原样出现在题面、重复命令组、长命令和单例工具等提示；它是风险富集样本，**不能用其错误比例推算整套数据的错误比例**。13 条评测变化／截断案例另有空白的独立人工复核表，尤其需要裁定 `lvmconfig` 参考答案冲突和 `hardlink` 题意歧义；目前签核数仍为 0。

在人工审查前，不应依据静态提示直接改掉或剔除训练数据。后续若建立修订版数据集，应逐条记录保留、排除或修正的依据，给新数据集单独版本和哈希，再用相同底座、推理协议和预先固定的评测集做对照。下一轮验证需要**独立于 KaliBench TRAIN 来源**的新题；已查询的 87 条只继续作为开发诊断。官方 TEST 留待最终协议定稿后使用。ABA 自动数据生成／选择应单列实验，不能把本次固定数据 SFT 算成 ABA 效果。

公开的[只读审计脚本](../scripts/audit-kali-qwen-train512.py)在持有获许可的私有 TRAIN 文件时可重算；它不会执行命令或加载官方 TEST。[前次 SFT 与内部复测](KALI_QWEN_UNQUERIED_CONFIRMATION_ZH_2026-10-28.md)保留原始自动评分 18/87→26/87，本审计不改动该结果。
