# KaliBench：外部来源通用命令保持题候选审核（2026-10-28）

## 目的和来源

已有的 24/72 条保持题和 72 条确认题都已在先前实验中揭晓，不能再当盲测。本轮只为**通用命令能力保持**寻找不同来源的待审核候选，不作为 KaliBench 领域训练金标，也不构成新的独立盲测。

来源为 [mecha-org/linux-command-dataset](https://huggingface.co/datasets/mecha-org/linux-command-dataset)，固定版本 `d3883ec38c0458a73a0b8aef19103cb2d006c87c`，原始 `linuxcommands.json` SHA-256 为 `81b33a65b80134875706fe005601f8b75dee726e91c4b632a517790e2b9ab175`。数据卡标注 Apache-2.0，共 8,669 条自然语言与命令配对。数据卡的许可标签和“命令已测试”陈述来自发布者，**并非我们对每条题目来源或正确性的独立验证**。原始数据保存在私有研究目录，没有复制进公开仓库。

## 可复现筛选和发现

先固定只读命令家族、禁止 shell 控制字符、特权／网络／写入动作、绝对路径、长度上限、按 SHA-256 排序和每家族最多三条的规则。初版规则的 JSON 转义有误，意外把字母 `r` 当作禁用字符；保留初版与失败输出后，在任何模型评测或金标准准入前修正并重跑。这是筛选代码错误，不是数据性质。公开仓库提供[修正后的规则](../configs/kali-external-utility-selection-2026-10-28.json)与[只输出汇总的复现脚本](../scripts/reproduce-kali-external-utility-screen.py)；用固定版本的原始 JSON 运行即可核对筛选计数，脚本不会执行候选命令。

风险标记包括依赖主机状态、递归遍历需要隔离夹具、通配符、异常大的单位、选项内含绝对路径，以及可能持续运行的 `tail -f` / `free -s`。自动规则只能排除显眼的不合适内容，不能证明题意、命令、等价答案或许可完全正确。没有风险标记的 8 条也没有获得金标资格。

精确重叠扫描只覆盖明确列出的 22 个本地 Kali JSONL 文件，并且刻意排除官方 TEST；零精确重叠不证明语义独立、训练前未见，也不能排除原底座预训练时接触过这个公开数据集。我们已查看候选内容并用它设计审核，因此**这批题不是盲测**。数据集也不提供适合本项目的独立官方保留集声明。

## 下一步准入门槛

私有 `review-queue-private.json` 记录每条候选的原题、命令、风险标记和待审状态。由未参与本轮筛选的人逐条检查：来源及再分发权利、题意与命令的一致性、等价答案、是否能在离线合成夹具上限时执行，以及和已有题的实质近重复。对可能无限运行或读取真实主机状态的命令，先剔除或用固定夹具／严格超时另建任务，**不能直接执行原始数据集命令**。审核通过后才另行冻结新评测协议；仍需一份真正锁定、未用于调参的独立来源保持集。

本轮没有新 GPU Job、SFT、ABA 原生数据生成或正式评测。先前保守确认门槛仍失败，正式默认模型仍为原底座。公开结果只含汇总、源版本和哈希；逐题内容、原始数据、审核队列留在私有研究目录。
