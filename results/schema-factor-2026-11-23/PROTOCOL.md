# Single-source supervision controls and a prospective transfer check

The student is Qwen3-8B. Training uses one previously verified local schema-export question from KaliBench TRAIN. The primary comparison replaces a topical sentence with a short statement of the decisive condition. A second comparison replaces neutral prose with one exact copy of the correct command. Crossing these choices produces four auxiliary targets of exactly 59 student tokens each. The fifth arm has only the shared final answer target. The visible explanation is masked in every arm. Answer, format and auxiliary losses have respective weights of 1.0, 0.1 and 0.5, averaged within their segments. Frozen text and counts are in [the protocol](protocol.json).

All five arms start from the same initialization within a training seed. The run uses three training seeds, saves adapters at 16, 32 and 64 steps, and evaluates the specified 64-step checkpoint without model selection. Four prompts are generated in the same batch with two decoding seeds per checkpoint. The primary outcome counts strict passes on the three same-source variants. The original prompt is a separate memorization check. Decoding seeds and synthetic files do not increase the number of independent sources. [GPU worker](worker.py)

A separate test freezes the four previously trained checkpoints before generating on three additional original TRAIN questions. All four checkpoints receive the same prompts and decoding seeds. One source asks for UUID and LABEL fields in export format. The native publisher command also emits a device-name field. Record publisher equivalence and literal fields-only behavior separately where a generated output makes this distinction relevant. The other sources ask for a static instruction table and demangled names in a synthetic compiler statistics file. Two closely related statistics-file prompts were calibrated, with only the first used for this comparison.

The single-source diagnostic and the prospective test serve different purposes. The former controls the content and length of auxiliary supervision. The latter evaluates the transfer of the earlier raw-trajectory checkpoints. Additional unique teacher-correct, student-repeat-wrong sources remain a prerequisite for the separately planned multi-source SFT comparison.
