# 本轮实际执行代码快照

这里的代码逐文件匹配实际提交 bundle 或原生运行封存 SHA。`fixed-core` 是固定 SFT 与带精确前缀重放的 E0 推理；`native-core` 是原生候选的相同数值训练/推理；`native-current` 是完成轮的原生编排。`native-prior-invalid-candidate` 是保留的先前协议无效尝试，A1分支交付了E0，不能称为有效A1交付。若存在 `native-prior-timeout`，它是另外的先前超时尝试，不是成功轮。相同代码在不同路径重复出现用于对应不同封存记录；导入并封存的模块不意味着每个模块都发起了新训练。

本快照供代码审查和持有合法私有输入者复现。原始题目、ID、参考答案、教师解释、预测、模型适配器和凭证未公开；数据准备模块及其私有产物也未作为公开可运行数据包发布。因此它不是开箱即用的全量基准复现包。公开聚合结果用仓库的 `scripts/verify-kali-curriculum-final-20261117.py` 核验，无需私有题目。

GPU worker 的 `/input`、`/scratch`、`/cache` 是原容器路径；账户连接和私有目录请使用自己的合法配置。`train_metrics` 区分适配器累计 32 步与当前原生轮真正新增步数；已有检查点复用绝不能计作新的参数更新。严格参考等价未覆盖的替代命令保持 UNKNOWN。

`source-manifest.json` 的 SHA 是实际执行源文件证据，不证明它们适用于其他数据、软件版本或硬件。数据/包版本、模型 revision、评测模式、样本规模与局限见上级报告。
