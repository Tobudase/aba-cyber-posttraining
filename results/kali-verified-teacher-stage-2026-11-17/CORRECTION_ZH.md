# 差距证据等级更正（2026-11-17）

原准备记录中的 **3** 是“教师至少2/3次通过、学生两种模式各至多1/3次通过”的低通过率候选数。**它不等于3个已证实的学生能力差距。** UNKNOWN 表示白名单验收器不能判断该命令形式，不能当作功能失败。

逐次合并两套夹具后，只有 **1个候选**满足教师至少2/3次通过且学生两种模式各至少2次明确FAIL；另 **2个候选**受UNKNOWN限制，保留为不确定。每种模式共3题×3次，thinking为2 PASS / 7 FAIL / 0 UNKNOWN；non-thinking为3 PASS / 3 FAIL / 3 UNKNOWN。一次试验需两套夹具都通过才计PASS；出现明确反例才可计FAIL。

本次只更正证据等级。23条教师示范的最终命令、6条回放、29行配对训练、冻结评分与选模规则均未改变；独立解题与正确教师命令不等于学生此前一定不会。原准备JSON和图中的3保留为历史低成功率规则计数，应结合本更正阅读，不再称为3个确认差距。AI审查与有限夹具都不是完美语义或专家金标准。
